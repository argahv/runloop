framing and timing. **None of them is final footage**: the Studio's immersive rework is still in progress,
and every product (C) shot is re-captured from the running app later (see `docs/shotlist.md`,
"Required real captures"). Files named `*_oldshell` show the pre-immersive shell (sidebar); `*_harness`
come from the town renderer's test harness (labelled "Fixture"). `standin_C6` compares two demo-mission
runs (Executed), not Claude Code sessions.
